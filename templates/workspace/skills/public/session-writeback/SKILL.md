# Session write-back

1. Append 2 to 5 lines to `<section>/memory/YYYY-MM-DD.md`.
2. Long-lived fact for one section: update that `MEMORY.md` and bump `Last updated`.
3. Durable cross-section fact: wiki page + index line + log entry.
4. `git pull --rebase`, commit only the files you changed, push.
